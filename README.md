# Function Grapher - Інтерактивний графік функцій

Сучасний веб-додаток для побудови графіків математичних функцій, створений з використанням React, Chart.js та Math.js.

## 🚀 Особливості

- **Інтерактивні графіки** - Побудова графіків у реальному часі
- **Підтримка складних функцій** - Тригонометричні, експоненціальні, логарифмічні функції
- **Налаштування діапазонів** - Гнучке керування областю визначення та значень
- **Сучасний UI** - Красивий інтерфейс з використанням Tailwind CSS
- **Приклади функцій** - Готові шаблони для швидкого старту
- **Адаптивний дизайн** - Працює на всіх пристроях

## 🛠️ Технології

- **React 18** - Сучасний UI фреймворк
- **Vite** - Швидкий бандлер та dev сервер
- **Chart.js** - Потужна бібліотека для графіків
- **Math.js** - Математичні обчислення
- **Tailwind CSS** - Утилітарний CSS фреймворк
- **Lucide React** - Красиві іконки

## 📦 Встановлення

1. Клонуйте репозиторій:
```bash
git clone https://github.com/vovka/grapher.git
cd grapher
```

2. Встановіть залежності:
```bash
npm install
```

3. Запустіть dev сервер:
```bash
npm run dev
```

4. Відкрийте браузер за адресою `http://localhost:5173`

## 🚀 Деплой на GitHub Pages

1. Побудуйте проект:
```bash
npm run build
```

2. Деплойте на GitHub Pages:
```bash
npm run deploy
```

## 📝 Використання

### Підтримувані математичні операції:

- **Основні операції**: `+`, `-`, `*`, `/`, `^` (степінь)
- **Тригонометричні**: `sin(x)`, `cos(x)`, `tan(x)`
- **Логарифми**: `log(x)` (натуральний логарифм)
- **Корені**: `sqrt(x)` (квадратний корінь)
- **Модуль**: `abs(x)`
- **Експонента**: `exp(x)` або `e^x`
- **Константи**: `pi`, `e`

### Приклади функцій:

- `x^2` - квадратична функція
- `sin(x)` - синус
- `2*x + 1` - лінійна функція
- `exp(x)` - експонента
- `sqrt(x)` - квадратний корінь
- `1/x` - гіпербола
